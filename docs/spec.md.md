
# Instagram投稿管理・分析アプリ仕様書

## 技術構成
- Python + Streamlit（1つのファイル `app.py` だけで完結させる）
- 外部の有料APIは使わず、同じフォルダ内のCSVファイル（`insta_data.csv`）にデータを保存・読み込みする

## フェーズ1：データの登録と一覧表示（最初に作る部分）
- 入力フォームの項目: 投稿日、投稿内容（メモ）、ハッシュタグ、いいね数、保存数、リーチ数
- 機能1: 画面の「保存する」ボタンを押すと、`insta_data.csv` にデータが追記される
- 機能2: 保存されているデータの一覧を画面の表（テーブル）で表示する

## フェーズ2：分析とランキング表示（2回目に追加する部分）
- 保存率（保存数 ÷ リーチ数 × 100）を自動計算して表に追加する
- 保存率が高い順に並べ替えたランキングと、棒グラフを表示する

## フェーズ3：Obsidian連携（最後に追加する部分）
- 分析結果のまとめをMarkdown形式で画面に表示し、コピーできるようにする
